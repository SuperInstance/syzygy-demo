Settings — key rack & your own keys

Perception runs through a small Cloudflare Worker (the “key rack”) so no provider key ever ships in this page. The rack paces calls and caps daily house usage; when the house eyes are resting, this page plays a recorded real session instead.

Bring your own key (optional). Paste a provider key and it is stored only in this browser (localStorage). Per call it is passed through the rack as a one-time header — the rack uses it for that single call, never stores or logs it, and house caps don't apply. It is never sent anywhere else.

Honest limits (same as the local version): hosted MiniMax reads take ~9–15 s, so the agent plays at reading speed; the model sometimes misreads floor texture as creatures; this engine has no fire button, so Hunter “engages” by pursuit to contact range. Prefer your own machine? The Node server version in the repo runs the identical loop locally. Part of the Syzygy program.
